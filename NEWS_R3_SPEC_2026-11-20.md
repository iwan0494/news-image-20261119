## ARSITEKTUR KODE R3 (beda total dari Level Eclipse)

Level Eclipse: `main.py` cuma menyalin PNG pra-render (copyfile), `render_poster.py` satu skrip CLI dengan fungsi font_for/wrap_lines/draw_masthead/draw_lead/draw_story/draw_footer/render, data sebagai tuple (DATE_LABEL string, LEAD tuple, STORIES list 5 tuple). **R3 beda total:**

- **`main.py`** — memakai `pathlib` (Level Eclipse melarangnya — R3 justru memakainya), satu fungsi `build()` yang memanggil renderer dan menulis output. Ambil direktori output dari `MAKEFUN_OUTPUT_DIR` (default `/output`), buat dengan `Path.mkdir(parents=True, exist_ok=True)`. Terima argumen opsional `--out` (argparse). Setelah menulis, verifikasi file ada dan ukurannya ≤ 1 MiB, lalu cetak ukuran + sha256 ke stdout. File tidak ketemu/validasi gagal → stderr + `sys.exit(1)`.
- **`poster.py`** — mesin layout sebagai `Poster` class (menyimpan Image + ImageDraw + font). Method: `banner()`, `stats()`, `features()`, `tiles()`, `map_and_more()`, `datecheck()`, dan `render()` yang memanggil semuanya berurutan lalu mengembalikan image. Sebuah `Style` dataclass untuk warna + ukuran font. Helper pemuat font bernama `load_font` dengan cache dict (nama beda dari Level Eclipse). Helper gambar: `draw_summit()`, `draw_court()`, `draw_climate()`, `draw_map()`, dan `draw_icon(kind)` untuk ubin. Semua digambar dari primitif PIL (rectangle, ellipse, polygon, line, arc) — tanpa file gambar eksternal, tanpa network.
- **`stories.py`** — data berita sebagai list of dict (BUKAN tuple). Key bebas dipilih sendiri oleh builder (misal `kicker`, `headline`, `body`, `source`, `place`, `art`). Koleksi: `FEATURES` (3 dict), `TILES` (8 dict), `BRIEFS` (14 dict), `STATS` (6 dict), `LEFT_OUT` (list string), `REGIONS` (list). Builder menyusun struktur datanya sendiri dari fakta di bawah — jangan menyalin blok kode dari spec ini (spec ini tidak berisi kode).
- **Font:** pakai DejaVu (Serif untuk headline, Sans untuk label, Sans Bold untuk kicker). Builder mencari file font di path sistem yang umum; kalau tidak ketemu, fallback ke `ImageFont.load_default()`. Jangan hardcode satu path saja.
- **Ukuran:** canvas 1024×1024, RGB, output PNG. Target ukuran file JAUH di bawah 1 MiB (Level Eclipse 102.416 byte — R3 boleh lebih besar karena lebih banyak gambar, tapi tetap ≤ 1 MiB).
