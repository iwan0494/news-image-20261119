## ARSITEKTUR KODE R4 (sama seperti ronde 3 + bootstrap sys.path)

- **TIGA file, dan main.py ME-RENDER saat jalan (bukan menyalin PNG).** Tidak ada file PNG pra-render di repo. Program menggambar poster dari nol setiap kali dijalankan, lalu menyimpan ke `/output/entry.png`.
- **`main.py`** — memakai `pathlib`, satu fungsi `build()` yang memanggil renderer dan menulis output. **PALING ATAS, SEBELUM impor `poster`/`stories`: bootstrap `sys.path`** (lihat Diagnosis di atas). Ambil direktori output dari `MAKEFUN_OUTPUT_DIR` (default `/output`), buat dengan `Path.mkdir(parents=True, exist_ok=True)`. Terima argumen opsional `--out` (argparse). Setelah menulis, verifikasi file ada dan ukurannya ≤ 1 MiB, lalu cetak ukuran + sha256 ke stdout. File tidak ketemu/validasi gagal → stderr + `sys.exit(1)`.
- **`poster.py`** — mesin layout sebagai `Poster` class (menyimpan Image + ImageDraw + font). Method: `banner()`, `stats()`, `features()`, `tiles()`, `map_and_more()`, `datecheck()`, dan `render()` yang memanggil semuanya berurutan lalu mengembalikan image. Sebuah `Style` dataclass untuk warna + ukuran font. Helper pemuat font bernama `load_font` dengan cache dict. Helper gambar: `draw_summit()`, `draw_court()`, `draw_climate()`, `draw_map()`, dan `draw_icon(kind)` untuk ubin. Semua digambar dari primitif PIL (rectangle, ellipse, polygon, line, arc) — tanpa file gambar eksternal, tanpa network.
- **`stories.py`** — data berita sebagai list of dict (BUKAN tuple). Key bebas dipilih sendiri oleh builder (misal `kicker`, `headline`, `body`, `source`, `place`, `art`). Koleksi: `FEATURES` (3 dict), `TILES` (8 dict), `BRIEFS` (14 dict), `STATS` (6 dict), `LEFT_OUT` (list string), `REGIONS` (list). Builder menyusun struktur datanya sendiri dari fakta di bawah — jangan menyalin blok kode dari spec ini (spec ini tidak berisi kode).
- **Font:** pakai DejaVu (Serif untuk headline, Sans untuk label, Sans Bold untuk kicker). Builder mencari file font di path sistem yang umum; kalau tidak ketemu, fallback ke `ImageFont.load_default()`. Jangan hardcode satu path saja.
- **Ukuran:** canvas 1024×1024, RGB, output PNG. Target ukuran file JAUH di bawah 1 MiB, tetap ≤ 1 MiB.
